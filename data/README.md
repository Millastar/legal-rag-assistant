# 法律知识库说明


## 数据范围

- 205 个唯一条款；
- 《中华人民共和国劳动法》107 条；
- 《中华人民共和国劳动合同法》98 条；
- 每个 JSON 键为“法律名称 + 条款编号”，值为对应条文正文。

中国人大网的现行有效法律目录列明：《劳动法》为 2018 年修正版本，《劳动合同法》为 2012 年修正版本。可通过以下官方页面复核：

- [中国人大网：现行有效法律目录](https://www.npc.gov.cn/npc/c2/c30834/202403/t20240301_434977.html)
- [人力资源和社会保障部：中华人民共和国劳动合同法](https://www.mohrss.gov.cn/xxgk2020/fdzdgknr/zcfg/fl/202011/t20201102_394622_wap.html)

## 使用边界

本数据集是项目演示使用的静态快照，不会自动同步法律修订、司法解释、部门规章或地方性规定。
